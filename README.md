# ServerPortfolio 문서

## 1. 개요
C# 및 Socket 기반의 멀티플레이 게임 서버. Unity 클라이언트와 연동하며, 다양한 기능을 포함하여 확장성을 고려한 설계를 적용합니다.

## 2. 시스템 구성
- **클라이언트:** Unity
- **서버:** C# SocketAsyncEventArgs 기반 비동기 소켓 서버
- **DB:** SQLServer (Entity Framework 사용)

## 3. 아키텍처 다이어그램
```plaintext
+------------+        +----------------+        +------------+
|  Client    | <-->   | C# Multiplay   | <-->   |   DB       |
|  (Unity)   |        |  Game Server   |        | (SQLServer)|
+------------+        +----------------+        +------------+
```

## 4. 주요 기능
### 4.1. 네트워크 통신
- `SocketAsyncEventArgs` 클래스를 활용하여 비동기 소켓 작업 구현
- Protobuf 직렬화/역직렬화를 사용한 네트워크 데이터 전송
- 이벤트 기반 처리 방식 적용하여 서버 응답성 향상

### 4.2. 로그인 및 인증 시스템
- `ASP.NET` 기반 로그인 인증 로직 구현
- 사용자 정보 및 세션 관리를 위한 데이터베이스 연동

### 4.3. 서버 성능 최적화
- `JobQueue` 구조를 활용한 스레드 간 작업 효율성 증가
- 이벤트 기반 모델을 활용한 빠른 데이터 처리

### 4.4. Unity 클라이언트 연동
- Unity에서 C# 서버와 TCP 통신 구현
- JSON 및 Protobuf을 활용한 요청/응답 처리

### 4.5. 게임 컨텐츠 제작
- 인벤토리 시스템 구축 (아이템 추가, 삭제, 사용)
- 채팅 시스템 (일반 채팅)
- 상점 시스템 (아이템 구매, 판매)
- 퀘스트 시스템 (퀘스트 수락, 진행, 완료 보상 지급)
- 우편함 시스템 (메시지 송수신 및 관리)

### 4.6. 데이터베이스 연동
- Entity Framework Core를 활용한 데이터 저장 및 활용
- 사용자 및 게임 데이터 관리 (캐릭터 정보, 퀘스트 진행 상황, 아이템 보유 현황 등)

### 4.7. 클라우드 서버 배포
- 로컬 호스트를 클라우드 공용 IP로 포팅하여 멀티플레이 구현
- Azure 활용한 서버 호스팅

## 5. 개발 환경
- **IDE:** Visual Studio 2022
- **Framework:** .NET 8.0
- **Database:** SQLServer
- **ORM:** Entity Framework Core
- **Serialization:** XML, Protobuf
